C&O 1943 Piedmont/Mountain Sub Color-Light

Draft signal system definition for a C&O Virginia Division layout set in 1943, covering the Louisa-Gordonsville-Charlottesville-Staunton-Afton stretch of the Piedmont and Mountain Subdivisions. Hand-built starting point - not an official JMRI-distributed system, and not yet loaded/validated in a running copy of JMRI. See the reference notes inside aspects.xml for what is and isn't confirmed against period sources.
